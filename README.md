# 众生行记 · 平面设计交互图录

以《明日方舟》六周年 PV 与「众生行记」活动界面为视觉参考的平面设计交互作品。页面不使用角色立绘，也不再包含映像（影片）部分：主视觉、干员档案与行迹图版都是实时绘制的平面构成——手绘感的圆环与标线、渐细笔刷、光刃碎片、光环、外框数字（套印错位）、镜像衬线字母、半调网点、马赛克、扫描故障条、节点星座、六边形组、Y 轴标尺、竖排文字柱、套准与裁切标记、色票与条码。技术栈为 TypeScript、Three.js、Vite。

## 直接打开

双击 **`双击打开.html`**，选择 Edge 或 Chrome 打开。这个文件包含全部交互代码、图形与活动 BGM，不需要 Node.js、不需要联网，也不需要启动终端（约 4.4 MiB）。

声音默认关闭，点击右上角声音按钮开启（界面音效与活动 BGM）。收藏和设置保存在当前浏览器；浏览器限制本地文件存储时，仍可浏览，但收藏可能无法跨次保存。

## 本地服务与源码开发

已安装 Node.js 24 时，也可双击 `启动.cmd`。终端显示网址后会尝试打开默认浏览器；若没有自动打开，复制终端中的 `http://127.0.0.1:端口/` 到浏览器。保持终端开启，关闭终端即可停止服务。默认端口 5173；端口占用时自动寻找下一个端口。

GitHub 仓库不包含 `dist/`。下载后可直接打开离线 HTML；使用本地服务前，先运行 `npm ci` 和 `npm run build`。修改源码时：

```powershell
npm ci
npm run dev
```

也可双击 `开发启动.cmd`。生成网页构建及离线 HTML：

```powershell
npm run build
npm test
npm run verify
```

`npm run build:offline` 仅重新生成离线 HTML。正式本地服务使用 `dist/`，改完源码需重新构建并刷新浏览器。

## 个人网站样例

`personal.html`（离线版：双击 **`个人网站样例.html`**）是用同一套模板做的个人作品集示例，虚构身份「林叶 · 交互设计师」：

| 页面 | 沿用的模板 | 内容 |
| --- | --- | --- |
| 序章 | 首页 | 姓名大字、主视觉图版（环形铭文为个人信息）、快速入口 |
| 关于 | 人员图版 | 姓名字母汇聚、简介、个人图版、圆弧 ＋ 节点显示要点 |
| 作品 | 行迹地图 | 每个作品一个节点（PROJECT / LAB / NOTE / NEXT），面板含标签与项目链接 |
| 能力 | 羽兽图谱 | 每只鸟携带一项能力，悬停读取、点击放飞，右侧列表可定位 |
| 联络 | 双手契约 | 指尖相触后展开联系卡片，可一键复制邮箱 |

**改成你自己的**：只需编辑 `src/site/profile.ts`（姓名、简介、要点、图版图标与星级、作品、能力、联系方式），然后 `npm run build` 重新生成。主视觉和个人图版是绘制的图形，不需要照片；作品预览默认使用游戏关卡预览图占位，公开发布前请换成自己的截图。

## 本机游戏素材

`public/assets/game/` 中的 70 件素材由 `scripts/extract-game-assets.py` 从本机《明日方舟》PC 客户端提取：活动复刻包 `permanent_sidestory_32_the_masses_travels.ab`（地图长卷、图集碎片、入口徽章）、关卡预览与活动系统 BGM（截取前 96 秒）。脚本不提取角色立绘，图集中属于角色立绘的裁片（眼部、发丝、侧像）也已跳过。客户端资源包使用改动过的 LZ4 块格式，脚本内置了解压。来源、裁切坐标与 SHA-256 记录在 `public/assets/game/game-assets.json`，`npm run verify` 会逐个校验。

```powershell
pip install UnityPy lameenc pillow
python scripts/extract-game-assets.py "F:/Hypergryph Launcher/games/Arknights"
```

## 文件结构

```text
双击打开.html              无依赖离线入口
启动.cmd / 开发启动.cmd   Windows 启动器（ASCII / CRLF）
dist/                    已构建的网页和本地素材
src/main.ts              页面、状态与交互
src/plates.ts            绘制的图版：人员图版、主视觉图版、行迹记录图版、职业图标
src/ui.ts                共享图标、印记、圆环与圆弧
src/site/                个人网站样例（profile.ts 为全部可编辑内容）
src/scene.ts             Three.js 场景：展开、检查、剖切、拾取、相机
src/sanctum.ts           圣堂建模（八组结构与各构件的展开方向）
src/graphics.ts          SVG 图形：编号鸟群、光环人像、点阵人形、六边形节点
src/fx.ts                准星光标、文字解码、转场、节点连线
src/route.ts             行迹关卡地图（五层视差、靠近显现、速度模糊、区域切换）
src/sequence.ts          行迹背后随拖动进度演出的序列
src/atlas.ts             图谱交互（放飞/框选/召回、羽翼展开、契约）
src/covenant.ts          双手契约：游戏手部贴图、构造线、距离变色、相触事件
src/data.ts              干员、记录、行迹节点与散落字母
src/util.ts              数值工具
src/style.css            基础布局与响应式样式
src/graphic.css          平面设计层：图纸、节点、图版、故障与转场
src/assets.ts            普通/离线素材地址切换
public/assets/game/      本机游戏客户端提取的地图、碎片与 BGM
scripts/                 本地服务、离线打包、资源校验
tests/                   数据、图版与圣堂结构测试
_removed/                已移除的映像与立绘（源码与素材，不参与构建）
VALIDATION.md            实际验证结果与未验证范围
THIRD_PARTY_NOTICES.txt   第三方组件及素材说明
```
